# Setup and data

Use Python 3.11, Isaac Sim 5.1.0 and IsaacLab commit
`18c7c58d7a6758b6119401945b881e21c8ec0392`.
Install IsaacLab following its installation guide, then:

```bash
pip install -e source/scaletrack -e source/my_rsl_rl
pip install mujoco pytest
```

The K1 MJCF and USD are included. Data and checkpoints are not bundled.
The preparation tools in `scripts/k1/` expose their required inputs
with `--help`: `prepare_bones.py`, `prepare_lafan.py`, `retarget_lafan.py`,
`pack_library.py`, and `merge_libraries.py`. Use the exact K1 morphology
conversion before packing LAFAN. Do not mix previous IK outputs with this library.

## Data

BONES source: the BONES-SEED/SOMA `k1_final` release.
All 142,220 clips are retained, including the corrections already present in
that selected version. The loader verifies the CSV schema, frame sequence,
units, finite values, and complete inventory. Root Euler angles use extrinsic
xyz, verified against the original loader. Conversion uses cm to metres,
degrees to radians, linear joint/position interpolation and quaternion SLERP
from 120 Hz to 50 Hz. No extra filtering, clipping, lifting, or frame removal.

LAFAN source: `TonyZhang1999/xwbc-retarget-data`, revision
`b4e169f460bd68b27e04e75c99be6e0affbfe046`, `booster_k1.tar.gz`, SHA256
`92fafe9e6372bf08b26061cc7ed4356f9f5c4bbffce646a86a0574a331112e42`.
All 77 clips are retained. The source K1 hip attachment differs from the
BONES model by 15 mm. Source FK was independently reconstructed and verified.
The final morphology conversion preserves every joint angle and the root
orientation, and solves the root translation from both world-space feet.
Both foot poses must agree within 20 micrometres/radians; otherwise it fails.
This is an exact rigid alignment of congruent leg chains, not a floor lift.
All frames passed, with maximum foot position error 8.27 micrometres.
Earlier joint-IK outputs were rejected for newly introduced temporal jumps
and are excluded from the final library.

Packed output must contain `train/` and `eval/` directories.

| Partition | BONES clips | LAFAN clips | Total frames at 50 Hz |
|---|---:|---:|---:|
| train | 140,791 | 64 | 52,042,528 |
| eval | 1,429 | 13 | 688,611 |

BONES splits hash each source name with its mirror suffix removed, keeping
mirrors together. LAFAN subject 5 is held out. This is a deterministic source
split, not a claim of complete subject/action isolation for BONES. The two
corpora retain their natural frame representation; no artificial equal-source
sampling is added. The upstream return-based sampler remains in use.
Packed fields are generated by batched exact FK and compared byte-for-byte
when merged. `INCOMPLETE` libraries are refused by the runtime loader.

## K1 model and training interface

- 22 named joints, 57-dimensional state, 56-dimensional model increment.
- 14 tracked bodies, 8 ScaleBFM sparse/full tracking modes. The torso mode
  maps to K1's head link because K1 has no independently actuated waist.
- Joint order comes from the actual Isaac articulation and is explicitly
  mapped to each source order; no positional assumptions cross this boundary.
- Fixed MJCF frames are represented in FK. The USD importer input excludes
  only massless empty leaf frames; retained masses/inertias/transforms are
  checked against the original MJCF. One articulation root is required.
- 200 Hz physics and 50 Hz policy; effort, velocity, armature and PD gains
  are explicit in `scaletrack/robots/k1.py`.
- Registered tasks: `K1-BFM-Transformer-Tracking` (NPZ/YAML PPO),
  `K1-BFM-Transformer-Tracking-Packed-PPO` (packed PPO), and
  `K1-BFM-Transformer-Tracking-SuperMimic`.


## Training and checks

`launch_a10.sh` preserves the eight-A10 training recipe: eight ranks,
512 environments per rank, seed 42, 256 world-model and imagination samples
per rank, actor activation checkpointing, and no world-size learning-rate scaling.
Set `PYTHON`, `NPROC_PER_NODE`, or `SCALETRACK_COMPILE_CACHE_DIR` as needed.
Additional training arguments are forwarded to the trainer.

```bash
python -m pytest source/scaletrack/test/test_k1_model.py -q
```

This checks K1/G1 state derivatives and forward kinematics against MuJoCo.
Checkpoint continuation restores model and optimizer states; replay and
simulator state are rebuilt. It is not bitwise full-state resumption.

## Provenance

Based on Hxxxz0/ScaleBFM_Plus commit
`65e4d524bd31fdc4284ba8c6e624fb0b0127da03`.
K1 actuator settings derive from K1Lab commit
`30f015a61f9583cba664b5ea65b0a1c73fba57e2`.

and makes its launcher portable. No training algorithm
or default hyperparameter changes are introduced.
